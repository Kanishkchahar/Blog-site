Setup Vite App

⚠ Note
Tested on Fedora 40 Workstation Edition. Keep your system updated via sudo dnf upgrade before applying kernel and driver tweaks.

Setting Up a Fast Vite App

Quick walkthrough for initializing a high-performance frontend project using Vite and Node.js on Linux.

1. Quick Start

Run the following command in your terminal:

npx create-vite@latest my-app --template react
cd my-app
npm install
npm run dev
